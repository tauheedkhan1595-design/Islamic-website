# Noor Islamic Journal — Modular CMS

Node.js + Express + SQLite editorial website. Public readers need no account. The admin has a protected studio, smart paste, HTML-file import, drafts, publishing, editing, deleting, categories, SEO fields and database backup.

## Important security note
`ADMIN_SECRET_CODE` is a login secret. Anyone who obtains it can access the admin studio. Set a long, private value in Render Environment settings before making the site public. Do not place the real secret in GitHub or this repository. `SESSION_SECRET` must also be unique and private.

## Deploy to Render
1. Upload this project to a private GitHub repository.
2. In Render, create a Blueprint from the repository. `render.yaml` describes the service, persistent disk, syntax check and automated tests.
3. Set `ADMIN_SECRET_CODE` to your private code in Render Environment. Keep the value out of Git.
4. `SESSION_SECRET` is generated by Render in the blueprint.
5. Deploy. Visit `/admin/`.
6. Log in using your secret code. The app will keep the admin session in a secure, HTTP-only cookie.

This configuration uses a paid Render Starter Web Service because persistent disks are required for SQLite durability and free instances do not provide the required persistent disk setup. Render pricing/plans can change; check current plan availability in your dashboard.

## Local run
- Install Node.js 20+.
- Copy `.env.example` to `.env` and set both secrets to long private values.
- Run `npm install`, then `npm start`.
- Open `http://localhost:10000/`. Admin: `http://localhost:10000/admin/`.

## Smart Paste and HTML import
- Paste from webpages, Word/Google Docs copied content, or plain text.
- The editor preserves common semantic formatting and heuristically converts plain-text title-like lines and bullets.
- Import `.html` / `.htm` files directly.
- Always inspect Preview before publishing. Formatting cannot be recovered if the source clipboard contains only plain text. External scripts, event handlers, unsafe URLs, embedded images and styles are removed during sanitization.

## API
- `GET /api/v1/health`
- `GET /api/v1/articles`
- `GET /api/v1/articles/:slug`
- `POST /api/v1/admin/login` (JSON `{ "secretCode": "..." }`)
- `POST /api/v1/admin/logout`
- `GET /api/v1/admin/session`
- `GET /api/v1/admin/articles`
- `POST /api/v1/admin/articles`
- `PUT /api/v1/admin/articles/:id`
- `DELETE /api/v1/admin/articles/:id`
- `GET /api/v1/admin/backup`

## Tests
Run `npm test` and `npm run check`. Tests cover content normalization and route-level behavior. Do not treat a passing local test suite as proof that deployment, Render storage, or every browser clipboard behaves identically; verify the deployed service after setup.
